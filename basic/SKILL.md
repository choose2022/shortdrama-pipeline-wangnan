# 短剧全流程 AI 制作套件（基础版）

> 本版**不含任何已填模型卡**（04 模块只有空接口，按附录 I 自填）；需要 MiniMax H3 现成卡用 `shortdrama-pipeline`（H3 版）。两版模块正文一致。

## 触发条件

用户提出以下任一需求，或任务跨越两个以上环节时触发本套件：写短剧剧本、改编小说、分集规划、拆视觉资产、出分镜、写生成提示词、执行生成、剪辑、质检验收。

## 使用方法（入口只有一个文件）

**第一步永远是通读 [references/00-总控.md](references/00-总控.md)**——它是总入口，包含：

1. **七道前置锁**（赛道/素材来源/目标模型/画幅/交付形态/段缝衔接/画风锁）——任一未确认任务不开始，必须停下向用户弹选项；
2. **路由表**——把用户请求分派到对应模块文件；
3. **冲突裁决链**——用户指令 > 前置锁 > 规则级别 > 权威比较 > 交用户裁定；
4. **跨环节契约**——素材形态三档（M0/M1/M2）、参考图状态机（REF-/PLAN-/待补/明确文生视频）。

**第二步按路由表调用对应模块**：

| 文件 | 职责 |
|---|---|
| [references/00-总控.md](references/00-总控.md) | 总入口：前置锁、路由、裁决、契约 |
| [references/01-剧本链.md](references/01-剧本链.md) | 原著分析、分集规划、剧本撰写、去 AI 味 |
| [references/02-视觉资产.md](references/02-视觉资产.md) | 人物/场景/道具拆解、一致性、资产图提示词 |

| [references/04-生成提示词.md](references/04-生成提示词.md) | 图像/视频提示词语法、模型适配卡接口 |
| [references/05-生产与剪辑.md](references/05-生产与剪辑.md) | 跑图/跑视频/配音生产四步闸门、剪辑成片 |

## 硬纪律（读 00-总控 前先记住这三条）

1. **平台中立**：正文不绑定任何生成平台，模型专属语法一律收敛到 04 模块的「模型适配卡」接口，由使用者按实际工具填卡；
2. **素材形态四铁律**：不索要图片；不因缺图阻断阶段；不写不存在的图号；每次交付首行声明素材形态；
3. **防伪造**：不写不存在的文件号，不声称已核验而实际未核验。

## 依赖 skill 缺失时：自动安装引导（硬规则）

本包不收录任何第三方正文，但有几处会点名外部 skill。**别人拿到本包、机器上没有这些 skill 时，不许只说"缺了"就停**——按下面四步自动补，补不齐才交人。

**Step 0 · 实测，不许凭印象**
逐个在技能根目录查同名目录，查到才算有。要查的根（按实际环境为准）：`<workspace>/.skills`、`<workspace>/.user_skills`、平台内置技能目录、`<用户目录>/.agents/skills`。
禁止把「我记得装过」当成已安装。

**Step 1 · 自动装（能装就直接装，不用先问）**，按优先级：
1. **技能商店有同名** → 直接出示安装卡，一次最多 3 个，同名优先，不拿近似名顶替；
2. **本机有打包件**（如公共工具箱里的 `短剧全流程Skill套件` 一类目录，含 `SKILL.md`）→ 按规范结构拷进 `.user_skills`：`SKILL.md` + `references/`，拷完立刻跑结构自检；
3. **有仓库地址** → 整目录 clone / 整包下载进 `.user_skills`，**不许**逐份手抄正文（大文件逐字重录会污染条款）；
4. **四条都不可用** →停下，列「缺哪个 / 干什么用 / 三个候选来源」，等用户指路。**不许伪造已装**。

**Step 2 · 复检**
装完重列技能根，逐项标 `已装 / 仍缺`；「仍缺」必须写进本次交付首行的缺口声明，不许只在心里记。

**Step 3 · 降级，不阻断整条链**
仍缺的 skill 只影响它负责的那一环节：走 04 模块第三节通用律，或转人工复核位；产物首行写「未做模型适配 / 该项未自动校验」，该条结论只能写「未完成」，**不许写「通过」**。

本包点名的外部 skill（按环境实测，不预置死清单）：

| skill | 什么时候需要 | 缺了怎么降级 |
|---|---|---|
| `h3-prompt-writing` | 只有跑 MiniMax H3 时才需要（三栏/六段式的结构权威） | 缺 → 04 模块只按通用律写，首行声明「未做 H3 适配」 |
| `h3-video-prompting` | 同上，运镜 / 光照 / 音频的措辞口径 | 同上 |
| `short-drama-qc-standards-wangnan` | 06 质检要按 55 条基线判，权威文本在它那里 | 缺 → 只按 06 模块自带三级质检出结论，并写明「未对 55 条基线」 |

**禁止**：用不存在的 skill 名；写「已安装」而实际没装；把缺口写成通过；为凑清单编造来源或版本号。

## 安装与分发

- **AutoClaw**：技能商店导入本包（或整文件夹安装），对话中按触发条件自动调用；
- **GitHub**：整目录即仓库内容，clone 后把本文件夹放入技能目录，或直接把 zip 当手册投喂任意 LLM；
- **其他支持 Agent Skills 规范的平台**：SKILL.md 为入口，references/ 为模块正文，兼容直接挂载。
