## 附录 A：2 秒钩子库（通用 12 + 分类精选）

**通用**：动作顶点定格（0.5s 再爆发）/ 武器对撞火花爆发 / 角色直冲镜头 / 0.25x 慢动作命中 / 震地冲击波 / 拔刀金属闪光 / 空中下劈踢 / 双持旋武器 / 鞭链炸响 / 对手闪避后撤（追击制造纵深）。
**叙事/情绪类**：眼部大特写+光反射（0.5s 静止后瞳孔收缩）/ 变身白闪（≤0.3s）/ 气场爆发（颜色=属性）/ 樱吹雪 / 标题卡砸入 / 剪影对 dramatic 天空（天空占 60–70%）/ 十字高光打击帧（0.2–0.4s）。
**商业类**：微距细节 1 秒内拉出至全身 / Before-After 闪变 / 开箱揭示（Unwrap/Peel）/ 粒子凝聚成型 / 聚光乍亮 / 旋转揭背面 / 爆炸图合体。
选型纪律：按品类/题材匹配能量——奢侈品用优雅（聚光/材质特写），科技用快（粒子/变形），时尚用向往（转身/面料流动）；一场一钩，不堆叠。

## 附录 C：灯光速查

**三件套**（每镜必答）：key 方向+色温 / fill 比例（标准 3:1、戏剧 5:1）/ rim 有无+强度。
**常用配置**：三点式标准 / 伦勃朗 / 低调高对比（chiaroscuro）/ golden hour（45° 侧暖光）/ 正午硬顶光 / 阴天软平光 / neon（青紫品红）/ 烛光火光（低色温闪烁）/ 窗光 / 实景光源 practical / 轮廓逆光 rim-dominant / 体积光 volumetric。
**品类灯位表（商业）**：珠宝=30° 侧上硬光+少 fill+强 rim+黑丝绒底，旋转让刻面每半秒闪一次；电子=45° 冷 5600K key+50% 暖 fill；美妆=60° 顶位 3200K 漫射+80% fill；食品=45° 暖 3200K+70% fill；腕表=35° 冷光先表盘后侧厚再背透。
**色彩语义**：金=英雄/胜利/温暖；青蓝=冷/神秘；紫=魔法/超自然/王权；白=神圣。饱和度五档：30–50%（恐怖/悲剧）/60–80%（严肃）/100% 标准/120–130%（热血/OP）/150% 上限（超 150% 显廉价）。

## 附录 D：材质/面料句式（运动法+光法配对）

- 丝绸 silk：慢走+涟漪反光，逆光显光泽流动
- 天鹅绒 velvet：转体显绒毛倒向变色，侧光掠射，禁镜面反射
- 雪纺 chiffon：微风+逆光显半透
- 皮革 leather：掠射光显纹理包浆，慢转+纹理处定点停顿
- 金属 metal：硬定向光让高光随运动「跳舞」，拉丝面拍纹路方向
- 玻璃 glass：多向光+焦散，中速旋转显折射流动；写 Fresnel+折射
- 针织/牛仔：自然走动显折痕与重量
- 液体 liquid：背/侧光显色彩折射，倾斜让液体流动；写死边界（as far as X and no further）
- 木质 wood：暖漫射显纹理走向
- 皮肤 skin/wax：写 SSS 次表面散射
**金属质感对打**：裸拳打布料不出火花——材质响应必须匹配（法术对撞是光爆不是电焊火花）。

## 附录 F：打斗动作词库（汉化精选）

- **拳脚**：直拳/摆拳/上勾/肘击/膝撞/正蹬/侧踢/回旋踢/扫堂腿/飞膝
- **摔投**：抱摔/过肩摔/夹颈/地面缠斗/十字固/断头台
- **兵器**：拔刀术/居合斩/撩刀/格挡反劈/剑脊格挡/枪出如龙/棍扫
- **流派短语**：咏春（短桥贴身连打/膀手消解）、八极（顶肘/贴山靠）、太极（引进落空/缠丝）、MMA（低扫接抱摔）、gun-fu（收枪换弹近战）
- **玄幻**：剑阵（万剑归宗=三维鱼群轨迹）/ 法相（按比例尺铁律）/ 掌心雷/护盾写明发生器与覆盖扇区
- **强化关键词**：动态招式→残影/速度线/衣袂横拖；法术→标注灵气方向（前推/上冲/下劈/爆散/环绕）；手部密集招式→「五指分明」；对手语义→目标高度参照+虚化对手剪影
- **表演幅度**：武打全身位移 3s 塞 8–9 拍可行；表情节拍一镜 ≤2–3（限脸不限肢体）

## 附录 G：风格词典（动画/动漫精选）

**日漫 11 类**（选一不混）：少年热血（130%+ 主色/速度线/冲击帧）/ 青年剧（60–70% 冷调）/ 魔法少女 / 机甲 / 异世界 / 日常（80% 暖粉彩/固定机位+角色运动）/ 体育 / 黑暗恐怖（30–50% 去饱和）/ 恋爱喜剧 / 赛博朋克（暗冷底+150% 霓虹点缀）/ 校园超自然。
**日漫质感三律**：受限动画+关键冲击帧（两关键帧+speed lines 填隙/smear frame）；内心状态视觉外化（禁「feels sad」写肩部下垂+泪光+眉内收）；静止也微动画（呼吸/2s 眨眼/发丝漂浮）。
**卡通 15 风**（1 主风格+至多 1 accent）：美式橡胶管/平涂矢量/水彩/剪纸/像素（≥24fps 防频闪）/黏土定格（12fps 断续感）/素描/油画剪影/3D cel-shaded 等；fps 按风格定。
**3D 渲染**：材质八要素（specularity/finish/SSS/折射/metallic/各向异性/色变/磨损）逐项过；运动一律 ease-in/out 禁线性；粒子写颜色+密度+路径+时长。

## 附录 J：体量换算速查

| 项目 | 数值 |
|---|---|
| 中文语速（剧情对白） | 4.3–4.5 字/秒 |
| 中文语速（解说旁白） | 4.5–6.5 字/秒；金句放慢 3–4 字/秒 |
| 英文语速 | 2.2–3.0 词/秒（按词不按字） |
| 台词安全线 | 整集 ≥3.5 字/秒；对话段 ≥2.0 字/秒且开口 ≥6 次/15s |
| 镜长 | 2–5 秒/镜；段 ≤ 单模型上限（默认 15s）；无台词氛围镜 ≤5s、纯氛围段 ≤10s |
| 剧本容量（标准档 90–120s） | 480–850 字/集；长档 820–1400 字；漫剧 330–620 字 |
| 时长换算 | 可拆时长≈台词字数÷4.5 + △行数×动作拍权重（对话 1.5s/混合 2.5s/行动 4.0s）+ 留白 3–5s |
| 15 秒窗口 | ≤95 字连续对白；动作单段 ≤40 字 |
| 中文页折算 | 对白为主 370–400 字/分钟；动作/悬疑 270–330；成段无声动作 230–260 |
| 交付响度 | 对白 0dB 基准；music -2~-4dB；SFX +1~+3dB；ambient -3~-6dB；总峰值约 -3dB |
