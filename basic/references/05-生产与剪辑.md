# 短剧全流程 Skill 套件 · 模块 05：生产与剪辑（生成执行 / 装配成片）

## 一、职责与适用条件

**职责**：①生产段——在用户明确确认后执行图片/视频/配音/配乐生成，结果落回项目；②剪辑段——把制作成果装配成成片，记录入出点/镜序/声音/字幕/交付规格。
**触发**：生成这张图/这批视频、配音、配乐、套剪、加字幕、统一响度、导出。
**不做**：创作提示词/镜头/台词/歌词（归 01–04）；质检结论（归 06）。

## 二、生产段：四步硬闸门（付费安全核心）

顺序不可合并、不可跳过：

1. **job（建任务）**：一种 modality（image/video/tts/music 不混）、明确数量、完整提示词、参考文件绑定、参数、输出路径、adapter 配置；大批量拆成用户能看清数量与成本边界的小 job，不把整季隐式塞进一次确认。
2. **prepare（完整预览）**：不调供应商；展示数量/提示词/来源条目/参考绑定/输出路径/是否覆盖/adapter；机械核对「可复制提示词与参考槽位」与文档一致，任一漂移即失败停止（fail-closed）。
3. **confirm（明确确认）**：用户**看到预览之后**明确确认。「继续」「都做完」「预算没问题」、上游已接受、确认过另一版，都不构成确认；job/提示词/参数/输出路径/输入任一变化→旧确认立即失效。
4. **run（执行）**：启动前消费一次性确认；成功或失败后再次执行都必须重新确认（防失败重试产生第二笔费用）。

### 生产细则
- **来源选择器**：图片任务取 IMG 条目；视频任务取 MOTION 条目；关键帧任务取 SHOT 冻结关键帧（只提取首帧；尾帧需先在图片阶段建独立 IMG 条目）。
- **参考绑定**：真实参考图逐张填 槽位/顺序/路径/中文名/用途/允许与禁止控制范围；带参考图却无绑定=任务失败不猜 role；一张图只占一个槽位。
- **引用语义**：按绑定顺序向提示词附加确定性引用说明（中文名/用途/允许与不得控制范围）；外部工具提交同样保留这组语义，不能静默丢控制边界。
- **中断恢复**：提交后就可能已计费——中断不等于重跑；先按供应商任务 ID 取回结果，确认原任务终态失败才重投且重投需重新确认；同一任务存在未决运行时禁止重新发起。
- **TTS**：从剧本读原句与表演要求，不在生产环节改词；表演要求映射为情绪/语速/音量/音调参数；同一角色每句用同一段已接受参考音色；只从预置音色合成，不做声音克隆。
- **音乐**：主题曲用已确认歌词；纯配乐不带歌词；不伪造时长请求字段；时长不能精确承诺时生成源音轨，落点/循环/淡入淡出/避让交给剪辑段完成。
- **凭据安全**：凭据只从环境变量或系统凭据存储读取；任务记录/确认记录/看板不保存密钥；归档排除私有输入、绝对路径与隐藏运行状态。
- **输出落盘**：结果原子复制到 `剧集/<EP>/制作成果/`；只接受与已确认 targets 完全一致的结果；「adapter 返回成功」不是质量结论。

## 三、剪辑段：装配成片

### 3.1 入口条件与纪律
- **素材已存在且可读**才开剪——不凭提示词、生产确认或回执开剪。
- **可取舍不可改写**：删一镜/缩一镜/换顺序属本段职权；改台词/改镜头职责/改起终状态回上游发修订请求；剪辑单可以让台词不出现在成片，但不能改台词是什么。
- **修订保留**：修订时保留未受影响的 CUT 条目；先更新剪辑单再渲染，不让成片领先于文档。

### 3.2 工作流程
1. **可用带先行**：每个素材文件从头到尾看一遍，写下实际可用时间区间与区间外发生了什么（起势静止/结尾漂移/发白/动作回弹）——这一步产出是事实不是决定。
2. **选点**：有台词镜先定位发声区间；可用区间内选叙事入出点并写理由（画面具体变化与叙事作用，不写「节奏需要」）。
3. **排镜序**：查相邻关系与接镜（景别/角度连接有视觉逻辑、场景转换有连接方式）；同一视频用两次源区间不得重叠（闪回/强调写明第二次作用）；同一静帧可多用；不能凭空出现没有素材来源的剪辑条目。
4. **声音**：处理声音接缝；响度分层（对白>音效>BGM）；音画同步；切点无可听音床硬切。
5. **字幕**：逐字铁律——每一个字取自剧本台词原文（不取转写结果，转写只用来定位时间）；标点照抄；多句编号写法自带相对时间且不重叠。
6. **画面文字**：视频模型写不对字——系统面板/倒计时/屏幕数字在画面留白由后期叠加；每一项都能在剧本 `[画面文字]` 行找到；相邻两段同一条角标首尾相接在成片里是同一个。

### 3.3 剪辑单（CUT 条目语法）
交付规格头（成片目标时长/画幅帧率/交付响度/字幕）+ 每段 `## CUT-<EP>-<序号> · <中文名>`：来源（MOTION/SHOT/IMG ID+项目相对路径）/ 入点·出点·时长（秒两位小数，出点−入点=时长）/ 取舍理由（入点+出点）/ 声音方案 / 画面校正（或「无」）/ 字幕 / 画面文字 / 音效 / 静帧段运镜 / 配音 / 环境声；未采用镜头行写理由，区分 **文件缺失** 与 **质量不可用**。

### 3.4 验收（check / render / verify 分工）
- check：素材比剪辑单新吗、区间自洽吗、来源 ID 可解析吗、字幕去标点能在剧本找到吗、画面文字可溯源吗、音效落在段内吗、字幕配音不越结尾不重叠吗。
- render：切段、静帧运镜、同场景自动接镜、拼接、混音、烧字幕与画面文字、统一响度。
- verify：只测量回报数字（响度/真峰/切点亮度音量变化/疑似坏帧），不改文件、**不给质量结论**——质量判断归 06；**不把「没测」写成「通过」**。
- 完成标准：每个 CUT 绑定真实素材与自洽区间；台词完整可听；字幕逐字等于剧本；实测响度在容差内（或超差已获接受）；未采用镜头全部写明理由。

## 四、输出物

- `剧集/<EP>/制作成果/`（images/、视频、音频、成片/）
- `剧集/<EP>/剪辑单.md`
- 运行记录与审计对账（本地任务历史、失败恢复、重复内容尝试、输出字节）

## 五、失败处理

- 生成失败重试需重新确认；连续失败升级到 03/04 模块改镜改词，不在生产环节反复烧钱。
- 素材不可用（缺文件/质量不可用）写进剪辑单未采用行并路由回对应模块补产。
- 依赖缺失（ffmpeg 等工具不在）如实失败说明，不用近似手段替代。
