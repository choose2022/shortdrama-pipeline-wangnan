# 短剧全流程 Skill 套件 · 模块 03：导演与分镜（决策 → 调度 → 分镜 → 动作专项）

## 一、职责与适用条件

**职责**：把剧本变成镜头设计——①导演决策（这场戏用什么镜头、为什么）②场面调度（人在空间里做什么、摄影机放哪）③分镜拆解（SHOT 条目+冻结关键帧）④动作打斗专项。
**触发**：定分镜、拆镜头、设计调度、写分镜表/故事板、打戏分镜、修「表演僵」「画面乱」。
**不做**：写剧本、生成视频提示词正文（归 04）、执行生成与剪辑。
**核心铁律**：无叙事功能的镜头删除而非改进——每个镜头能一句话说出它承担的叙事/情绪/空间信息；先 blocking 后取景：身体在空间中做什么先定，再放摄影机。

## 二、输入与前置

- 剧本（01）+ 视觉设定（02）+ 画幅锁 + 目标模型原生时长区间。
- 用户已锁定的镜号/机位/切点/动作/声音结构作为硬约束原样继承，改进建议只围绕获准范围。

## 三、导演决策（先想清楚再用镜头）

1. **顺序铁律**：写每颗镜头前先答「这颗要让观众感觉到什么」（用感受不用动作）→ 再定构图（机位高度/景别/人物位置/视线方向）→ 最后才写内容。验收先问「达成戏的目的了吗」再问「照分镜拍出来了吗」；没达成改构图而非细节。
2. **beat=压力变化**而非镜头变化；镜头家族九种：建立/关系/特写/插入/反应/转场/余波/主观/揭示——每颗从中选一。
3. **情绪锚点表**：每段切 3–5 个情绪节拍（每拍一句「角色在做什么+情绪是什么」）；选情境类型→分配权重（核心构图组合 80% 锁死、辅助 15%、增强 5% 且每段最多 1 镜只给情绪峰值）；节拍间必须有变化，4 个相同情绪=戏没推进。
4. **构图雷区双态**：A 类可白名单解锁（须标注+配套约束+理由，如正面居中只给仪式威严情境）；B 类永不解锁（物体穿身等物理错误）。常规平视正面构图压至 30% 左右作呼吸与基准线；侧 45° 为短剧默认；大仰俯各 ≤3 次/集、荷兰角 ≤1/集、手持三级烈度对号——所有倾斜俯仰必须由画面情绪买单。
5. **影像基底契约**：3D/仿真人基底禁「特写×平视正面」组合（恐怖谷）；真人「特写+正面」≤ 特写总数 1/3；2D 手绘正面可用但同场连用 ≤2 次。
6. **人物特写占比 25%–40%**；每 4 秒至少 1–2 个有意图的镜头运动，全程固定=电视感；「固定机位」是合法且常更好的选择——对话段以固定机位+换嘴切镜为主力。

## 四、场面调度

1. **坐标系先行**：每场建空间坐标系与文字平面图（方位按场景说不按画面说——「桌北侧」不是「画面左侧」，机位一换左右就翻）。
2. **站位与视线**：单镜 ≥2 人时站位声明里每个具名人物必须写视线落点（身体朝向≠视线方向）；后来才进来的人开场不在场；摆了位的每人本段至少带到一次，带不了就写「段末离画」。
3. **轴线**：普通机位保持动作轴同侧；越轴必须先用中性正面镜头或可见连续越轴运动建立新关系。
4. **节拍闭环**：每个动作写 起势→路径→接触→落点→接收者反应；「他转身」不是镜头，「转到侧脸贴窗后停住」才是——每个动作写终态。
5. **写行为不写情绪**：禁「他很紧张」，写恐惧的身体表现（呼吸/喉结/下颌/眼睑/指尖/肩线/重心——8 部位可表达 90% 情绪）。
6. **道具账**：道具持拿/状态每次交接显式登记；依托物（靠着什么/拿着什么）在无走位段严禁跳变。

## 五、分镜拆解（SHOT 条目）

### 5.1 三层结构
- **段**（segment）：一次视频生成单元，≤ 目标模型单段上限（通用默认 ≤15 秒），按剧情单元分段、不跨场；
- **镜**（shot）：段内 2–5 秒剪切，认领剧本节拍；
- **关键帧**：每镜冻结一张起始帧（可选收尾帧）。

### 5.2 核心拆解规则
1. **节拍密度第一定律**：一个镜头 ≤2–3 个表情节拍，超了拆镜——模型会把超载节拍收敛成「平均运动」全部抹平且不报错。限脸不限肢体：全身位移类动作 3 秒塞 8–9 拍可行，拆镜理由改为「换角度」。切镜本身是表演（观众在切点重读角色状态）。
2. **景别由「必须入镜的内容物」决定**：有表情节拍的镜头脸占画高 ≥1/3；远景只做空间不做身份；表演够不够近是第一诊断——表情没执行/体格被抹平/画面杂，常见唯一根因是镜头太远。
3. **机位先于表情**：角色看的对象不在画面里就会看镜头——把机位放到角色看的方向；喝采的人不出现在主角背后（留在镜头外、活在声音里）。
4. **多人场拆正反打**：同框只留一两颗中景交代关系，每句台词/反应都是单人镜，机位放听话者的视线方向；同框 ≤3 人，超了必须带拆解说明。
5. **镜长由剧情倒推**：剧情→情绪节拍→时长，禁「段长÷镜数」等分；快慢呼吸交替覆盖 ≥3 个取值；爆发镜快切、金句镜留白；总时长允许比剧本标注短至 -25%，禁拉伸凑时（无台词氛围镜 ≤5s、纯氛围段 ≤10s）。
6. **台词预算**：台词秒数=字数÷语速（中文实测 4.3–4.5 字/秒），嘴要动的对白是硬约束；一句台词不跨两镜；台词密度（对话段 ≥2.0 字/秒、开口 ≥6 次/15s）是「常见毛病」默认倾向，剧情本身就是不说话的段（静场对峙/宣判/独白）可豁免但须显式标注意图——「一个人在吃/翻/走」不是静场是缺戏。
7. **镜头功能配额（对话段 15s）**：建立空间 ≤1 / 说话人 ≤3 / 听方反应 ≤2 / 微动作特写 ≤2 / 局势变化 1；反应镜头连续 ≤2；回合制切镜——一次切镜至少换 说话人/景别/角度/主体 之一；同一说话人不连续 ≥2 镜独占开口。
8. **场景站位**：一场多镜先在开头写固定锚点/各人相对位置/轴线/working side/哪镜改变站位；相邻镜机位角差 ≥30°、同景别不连续 3 镜；动作衔接 60–80% 重合。
9. **相对时间词先换算**再写进时间轴（「前半段首次出现」在 60s 作品里不得早于 30s）。

### 5.3 SHOT 条目字段（逐镜齐全，无内容显式写「—」，禁整行删）
`## SHOT-xxx · 中文名`：唯一职责 / 来源（以剧本真实场景 ID 开头）/ 时长 / 景别·机位 / 运镜（写行为和理由，固定也写理由）/ 起点→唯一动作→终点 / 声音；多镜场附场景站位；`### 冻结关键帧提示词`（只投影镜头起点，删除「终点才出现的东西」）；可选 `### 收尾关键帧提示词`。
**三条依据同格互不矛盾**：视觉依据（引用《视觉设定.md》条目）/ 图片提示词项（IMG ID 或「无」）/ 输入参考图（REF- 或 PLAN-）——成稿后从成稿正文反查一次填满，不编造 ID。

### 5.4 故事板图
每段一张多面板图：文戏 2×2 四宫格 ≥4 格 / 打戏 2×3 六宫格 ≥6 格（格数由动作复杂度定，禁机械凑九宫格）；七态动作相位（起始/过程/接触/顶点/结果/反应/出口）逐格对应；出口帧=下段入口帧；必出 CLEAN_GRID 干净版（零文字，供生图）；不出须写「豁免+理由」。

## 六、段缝衔接（多段生成的一致性命脉）

1. **尾帧锚定法（默认）**：末镜末 1 秒整秒「全体定格」（前置 0.5s 收束窗、末镜景别须装下全员）→ 截真实末帧作下段画面依据 → 下段首镜 0 级同档景别承接。
2. **换机位硬切**：末 0.5s 只收势不定格；剧情段划分+组内多机位的段缝走此法无需理由。
3. **空镜过渡**：1–2s 带戏剧任务、单集 ≤3 处。
4. **技巧型转场**：须有叙事意图、单集 ≤3、同段不连用 ≥2、术语禁裸写进投喂稿。
5. 跨镜记录「前镜结束状态/后镜开始状态」：位置/朝向/武器/伤损/破坏/持物——交接不清楚的段缝视为缺陷。

## 七、动作打斗专项

### 7.1 档位路由
- **R1 写实档**：现代格斗/警匪/追逐/喜剧打斗——升格慢镜默认禁用（仅用户要求且 ≤1s）；真人脸红线：参考图必须动漫/CG/绘画风。
- **R2 通用档**：武侠/冷兵器/常规动作——升格与冲击帧全片各 ≤1 次且只给决胜。
- **R3 玄幻档**：法术对轰/剑阵/法相——特效有生命周期，尺度四件套（画框分数+宏观量级+参照物+人物占比）缺一即废句重写。

### 7.2 动作因果链（打斗的语法）
1. **七拍链**：当前位置与支撑 → 发力/启动 → 攻击轨迹与目标 → 对手应对 → 接触或落空 → 受力结果 → 下一拍可用姿态。每个交锋读得出七拍；**失败动作（被挡/落空）必须存在**；禁同一击既被闪开又出现命中效果。
2. **四段式**（简版）：发起→防守/命中→受力或位移→恢复/新状态；换手/脱手/断裂/再取回必须发生在画面中。
3. **受力四通道**（每次重击选 2–3 项）：身体（重心失衡/落地缓冲滚动）、物体环境（护甲凹陷/断裂方向服从受力方向）、镜头时间（接触前极短停顿/冲击帧）、声音（挥动→接触材质声→余振→落地，因果顺序不错位）。
4. **物理铁律**：受力必有来源与方向（无支点不腾空、武器不瞬移）；**先接触后特效**（命中先于火星/震屏/音效）；每秒 ≤3 个主要动作；复杂起跳/翻转/落地给足时间；重击可见蓄力（触发→蓄力→锁定→释放→结果）。
5. **节奏**：张弛循环（buildup→impact→recovery→escalation），全片匀速高压=假；体力真实（约 15 次交锋后安排 3 秒喘息）；武器重量决定节奏（重武器大弧线长恢复，轻武器穿插进击）。
6. **多角色调度**：2v1 指定 1 人为镜头焦点、两攻方取夹角；3+ 人逐对写明「谁此刻在打谁」+画面分区（前景主战斗/背景次级虚焦）或波次进攻（1→2→3 递增）；一对多同一时刻最多 1–2 名对手精确前景攻防。
7. **破坏五级**：微动→表面伤→局部断裂→结构塌陷→地形改变（只用于终局）；破坏方向服从受力方向；残骸保留到结尾。
8. **升格/冲击帧配额**：写实片不用；一张一弛片各 ≤1 次只给决胜；全程高速片禁用仅终局 ≤0.3s 微停；短促升格实测写法——只覆盖命中瞬间约 0.3–0.5s 并写明「命中瞬间慢放半秒，随即回实时」。

### 7.3 对峙文戏模式（台词/视线/微动作驱动）
- 张力因果链：施压→承受→泄露或反制→新平衡；
- 15s 真人对峙=1–2 张力单元/5–8 镜；凝滞允许 4–6s 长镜缓推；
- 镜头功能配额同 5.2-7；台词按实际时长划分、一句台词不跨两镜。

### 7.4 N 宫格预演法（图生视频的打斗专用）
把打斗拆成 N 格 keypose 海报（默认 16 格 4×4）：海报图同时充当 视觉规划+视频参考图+动作字典。三条配套机制：
1. **参考图阅读协议**：视频提示词前置声明——格序=时间序（行优先）、排除 UI 注释层（编号/标题/箭头/轨迹线严禁渲染进视频）、人物场景以图为准不增不减；
2. **分镜执行清单**：时间戳逐格 `[00:00-00:01] 第01格｜招式名｜要点｜镜头标签`；每格 ≥0.3s、总长=成片时长、禁 0 秒跳过；末尾自检「确认 N 格全部出现」；
3. **keypose=运动中的瞬间**：每格写「爆发瞬间/接触瞬间/动作中段」，禁已完成定格姿态（死姿态作首帧会让视频「重新启动」断节奏）。
配额防站桩：N 格中 ≥⌈N/5⌉ 低桩、≥⌈N/8⌉ 腾空高位、≥⌈N/5⌉ 转身背身、≥⌈N/8⌉ 近景特写；起势与收势必须明显不同且不用「双手负后站姿」默认值。

### 7.5 打斗合规三类（全打斗强制）
- **A 版权脱敏**：扫六类专名（角色名/作品名/武器技能专名/门派/可识别地点/真实人名）——视频提示词零容忍；方向「去名留形」（年龄+性别+体型+服装+武器+气质）。
- **B 暴力软化**：过程而非结果（「推进中」代「命中」）、反应而非伤害、环境物理反馈、武指美学语言（剑势压向/劲道贯穿）、格挡闪避主导叙事。
- **C 平台中立**：正文零平台名，模型参数进适配卡。

### 7.6 轨迹图工作流（可选进阶）
需要精确控制走位时：①初始站位全景图（必需底图，双方全身入画、无轨迹线）+②人物轨迹图 或 ③人物+摄影机双轨迹图（②③二选一）。图语言：带箭头实线=移动、短虚线箭头=攻击方向、蓝色曲线=摄影机、数字标节点。**轨迹图回传前不出正式提示词**；正式提示词开头加固定行「轨迹线箭头编号只作调度参考，最终画面不显示」并写入禁止项；节点数≠镜头数。

## 八、输出与验收

- `剧集/<EP>/分镜.md`（SHOT 条目+故事板+站位）。
- 完成标准：剧本每场都有镜头承载（不拍的写「未拍场次+理由」）；每镜有唯一职责与叙事目的；三条依据同格互不矛盾；时长落在目标模型原生区间；段缝状态交接完整；机位/景别/轴线/视线/道具五维衔接自查通过。
- 每镜表演三要素自查：①叙事（推进了什么）②动作（可见身体动作）③表情（具象肌肉动作）——缺任一即「没在演戏」，纯风景镜/纯对白镜须说明叙事功能否则删并。

## 九、失败处理

- 台词承接：上游每句台词默认原样进分镜稿，无权删改——要精简只能在文末出《台词精简建议清单》并固定征询话术「你是精简还是不精简？」；无精简也要写一句「本稿全量承接上游台词」显式化。
- 同一镜头三次生成失败 → 改镜头（更短/更近/更简单/拆两镜/换反应或插入镜），不改提示词硬磨。
- 用户对机位方案犹豫时：一次只给 2–3 个机制不同的候选（改变主角策略/对抗来源/代价/冲突方式），不给「换标题式」的假候选。
