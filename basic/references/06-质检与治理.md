# 短剧全流程 Skill 套件 · 模块 06：质检与治理（规则分级 / 三级质检 / 基线清单）

## 一、职责与适用条件

**职责**：定义全链质检的规则分级、裁决与流程；对项目任一阶段产物做核对与审查；管理风险台账与放行。
**触发**：质检/审查/验收/过门禁/出报告/「这一集能不能过」/阶段间流转确认。
**不做**：代替负责人修改来源文件；重做设计；自行选边（冲突按总控裁决链上交）。

## 二、规则三分类（套件全部规则按此分级）

| 级别 | 定义 | 违反后果 | 判定三问 |
|---|---|---|---|
| 硬约束 | 违反=产物不可用或违反前置锁/红线 | FAIL，禁入下一阶段 | 产物无法用吗？违反前置锁或红线吗？「禁止/必须/不得」且无例外分支吗？ |
| 条件约束 | 触发条件满足时等价硬约束，门外完全不判 | 条件内 FAIL | 触发门命中了吗（如「打戏激烈度下限」仅打戏稿判）？ |
| 创作建议 | 默认倾向，可覆盖 | WARN，可修复或写明不改依据 | 有明确剧情/风格豁免声明吗？ |

误分级代价：把条件约束当硬约束→无谓拦截；把硬约束当建议→该停不停。**等级由清单定，检查者只报现象，不自己判等级。**

## 三、三态与三路校验

- **三态**：PASS 放行；WARN 逐条二选一（修复，或写明不改依据——禁不写依据就放过）；FAIL 修复并复验，不得带 FAIL 交付。
- **三路校验**：①机械可判（格式/引用/时长/编号/字数——脚本与规则核对）②AI 语义（因果/一致性/台词归属——模型逐项核）③人工看图看片（长相/表演/口型/混音/成片观感）。**防两条反模式：声称完成而未校验；把语义判断题塞进正则。**
- **机检 PASS ≠ 阶段 PASS**：机检只覆盖可机械判定项；语义与人工项必须逐项过。

## 四、三级质检流程

1. **第一级·机械核对**（每份文档交付即跑）：ID 解析（EP/SC/IMG/SHOT/MOTION/CUT/REF 全部能解析、引用可找到）；台词逐字抽验（4-gram 覆盖率 <0.5 缺失、<0.85 逐条核对）；时长区间与加总；素材形态声明与图号一致性（M0 无图号/M1 有接线单/M2 图像核验）；字幕逐字可溯源剧本；画面文字可溯源 `[画面文字]` 行。
2. **第二级·技能自检**（各模块交付前跑，见各模块自检节）：自检结果写入交付说明；自检是"自查"不是"终审"。
3. **第三级·独立审查**（用户点名或阶段放行时）：优先由未参与当前版本创作的审查者执行（条件不允许可自检并如实说明）。

## 五、独立审查规范（证据制）

1. **十个审查范围**：原著分析 / 故事剧本 / 资产连续性 / 图像提示词 / 分镜与关键帧 / 视频提示词 / 生产产物 / 整集成片 / 交付隐私 / 项目校准——只读对应资料，不预加载整个项目。
2. **先查可证明事实**（机械层），再带证据审内容（语义层）。
3. **跨文档综合链**：剧本事实→视觉设定→镜头职责→冻结关键帧→视频运动→下一状态；优先守住原意、知情时机与连续性，不奖励脱离来源的华丽提示词。
4. **finding 七要素**（缺一不算问题卡）：位置 / 必要短引文或冲突事实 / 对观众或制作的影响 / 必须达到的修订结果 / 负责模块 / 严重程度 / 规则等级 + open/closed。**「AI 味」「不够电影感」或无证据分数不能替代这些内容。**
5. **四档结论**：APPROVE / APPROVE_WITH_NOTES / REVISE（阻断交付的结构缺陷、经证据确认的内容缺陷、与已接受限制冲突）/ PROVISIONAL（关键输入不足）。
6. **四级严重度**：blocker（不安全/不可交付/会让流程走错）/ major（明显破坏理解、连续性或制作结果）/ minor（有具体影响不阻断）/ note（创作选择或可选润色）。
7. 缺输入时只停止依赖它的判断，其他问题继续汇总；无法读取媒体时明确限制，不从文字推断脸部一致/表演/口型/混音。
8. 问题卡格式：`## Blocker · REV-xxx · <标题>` + 七要素；修订要求按负责模块分组交回。

## 六、常驻基线：十阶段流转门

上游不通过禁止流入下一工序；严格串行，禁止跳工序前置生产（没过分镜不得批量生图）。

| 阶段 | 关键门禁（必检项） |
|---|---|
| 1 剧本前置 | 剧情逻辑/台词合规/人设统一/时长分配/版本确认；台词零丢失基线 |
| 2 分镜稿 | 镜头序列/构图/角色出镜/字幕安全区/段缝状态交接 |
| 3 生成图 | 角色一致/肢体手部/杂物乱码/光影统一/画质/背景一致/安全区 |
| 4 图生视频 | 运镜匹配/动态幅度/首尾帧/时长/帧率/同场色调/动作可读 |
| 5 剪辑转场 | 镜序与接镜/未采用镜头理由/同源区间不重叠 |
| 6 字幕 | 逐字等于剧本/时间轴不重叠/安全区 |
| 7 音频 | 配音逐字/音量分层（人声>音效>BGM）/音效同拍/时长对齐 |
| 8 成片合成 | 音画同步/全片色调/跨镜角色巡检/画面事故/片头片尾 |
| 9 上线终审 | 合规复审/导出参数/文件命名/包体校验/物料配套/修改闭环；台账未销项直接卡单 |
| 兜底 | 角色漂移/字幕批量错乱/音画不同步/光影跳变/高危崩坏 → 专项复检表 |

**分级退回**：剧本逻辑/人设问题回阶段 1 并联动重审分镜；换脸/造型崩坏/背景乱变回阶段 3；字幕/配音/音画错位回 6/7，不必重跑生图与动态。

## 七、题材专项层（可切换基线）

- 机制：常驻层（第六节）+ 选中题材专项层合并为生效清单；**专项只加严不豁免常驻层任何条目**；同层不并存两套同类题材基线。
- **题材必选前置（硬约束）**：质检启动前必须把题材清单呈现给用户单选 1 项，未选不许用；不得用上次那套顶替、不得按稿件内容反推、不得默认；报告首页写明所选题材与选择时间。
- 只读基线文件+命中的那一个题材文件，不全量读。
- 专业常识类题材（医疗/律政/刑侦/年代/戏曲）无自动校验器时列**硬性人工复核位**；缺口即未完成——该条结论只能是「未完成」不能是「通过」，缺时一句话提示补装/补人，不因缺工具停掉整份报告。
- 已知可挂载的题材校验器示例：军事装备与战术逻辑、修仙玄幻力量体系（含巨物尺度锁定）、历史服饰与器物年代、戏曲声腔板式、多语言口语合规。

## 八、台账与放行

1. **风险台账**：🟡级风险必须登记（阶段 9 前清零，否则终审直接卡单）；🔴阻断打回对应阶段；🟢不卡流转。
2. **放行待办四表**（报告末尾自动生成，禁手填/编造/省略，空表也写「无」）：①准入凭证缺口 ②风险台账未销项 ③缺校验器未完成条目 ④下一关前置预告。条目必须落到「补什么、谁补、补完跑哪几条」，写「建议处理」视为无效。
3. **签字栏**：核验人+日期+结论，不许空。
4. **报告即交付**：结论只写在回复里不算交付；未过 lint 的报告不得作为放行依据。
5. **禁止项**：整批盲跑、只信批量脚本结论、抽几条代表全量、跳过审计栏、汇总结论代替逐条明细。

## 九、改动复验三步（任何上游改动后必跑）

①局部验证（改动项本身）→ ②联动冲突检查（受影响下游逐项点名：改了分镜→提示词/参考绑定/剪辑单受哪些条目影响）→ ③全量审核 → 附《改动复验报告》。

## 十、失败处理

- 发现契约断裂只出报告并路由回责任模块，不代修。
- 审查者与创作者为同一会话时，在报告头部声明「未能满足独立审查条件」并降级结论为 PROVISIONAL。
- 校验器缺失：缺口条目标【人工复核·未自动校验】，列硬性人工复核位，不冒充通过。
