# 短剧全流程 Skill 套件 · 模块 02：视觉资产（一致性设定与图像提示词）

## 一、职责与适用条件

**职责**：从剧本拆人物/造型、地点/视图、道具/状态与跨场连续性，写成创作者可读的视觉设定；产出可直接复制的图像提示词（角色定妆/三视图、场景板/九宫格、道具图、状态变体）。
**触发**：拆资产、做设定、出角色图/场景图/道具图提示词、判断复用还是新变体。
**不做**：分镜、视频提示词、生成执行（路由见总控）。
**核心命题**：环境和角色是「要被生成几十次还得长一样」的资产——一致性来自锚点与参考图，不来自模型记忆。

## 二、输入与前置

- 当前范围剧本（01 模块产物）+ 已确认画风锁（总控⑦）。
- 素材形态声明（总控 M0/M1/M2）。
- 时代锚点证据不足时标「待决定」，不猜。

## 三、资产四分法（定所有权）

| 类别 | 定义 | 归属 |
|---|---|---|
| 身份 | 换了就不再是同一人/地/物 | 资产层拥有 |
| 变体 | 身份不变：服装/伤势/时段/天气/开合/持有改变 | 资产层拥有 |
| 镜头瞬态 | 姿势/视线/左右手/站位/机位 | 分镜层拥有 |
| 故事语义 | 知识/目标/关系/情绪 | 写作层拥有（只引用可见后果） |

每项资产先写「什么不变使它仍是同一资产」，再写本集变化；识别锚点必须**可见、可生成、可比较**（「补丁船篷」是锚点，「陈旧的氛围」不是）。

## 四、一致性规则（最高优先级）

1. **一组图只有一个根**：每个角色只出一张正面全身锚点（文生图），其余视图全部是「锚点+一句改图指令」；图与图之间不互相参考——坏一张重出一张，不连锁。一致性来自同一张锚点，不来自同一个模型。
2. **人脸靠大头照**：视频模型只给全身时脸易走样，锚点档默认补 正脸大头照+90°侧面+背面。
3. **出图提示词禁写角色名**（一致性靠参考图锁定长相，人名跨模型不稳）；唯一例外：分镜关键帧图提示词允许直呼角色名（配合设定图出图）。
4. **环境与角色两层资产不混**：空景提示词必须无人；站位只落在场景图上真有的东西旁。
5. **同批防撞车**：同一批出卡任务里互给其他对象名字（防长相/气质撞车）。
6. **冻结与过期**：锚点文件、画风快照、描述指纹三者冻结；任一变更→旧图全部标「过期」，只标记不删除；同一部剧全部同一画风，换画风=从锚点重出。
7. **年龄/性别/年代推不出必须问用户**——只有这三样不许编；其余自行补全不追问。

## 五、角色资产规范

1. **设定图版面**：左 大头照，右上 正面全身/侧面/背面三视图，右下 细节条（发饰/领口/袖口/鞋）；全身必须从头到脚完整入镜、**含鞋**、双手垂落不持物、表情中性、纯白背景。
2. **多格板硬规**：全图只允许一张可辨识的脸且落在面部特写格；三格全身一律「无脸」（头部完整但不刻画五官）；显式声明「全图共 N 格」；禁用 mosaic/无头 等字面词，用「无脸」表述。
3. **提示词要素**：年龄/性别/体型/发型发色/服装（上装、下装分开写）/鞋/脸型眼睛/符合人种·时代·身份/头身比（写实 6.5–7.5 头身防头大身小）；大头照只用上装描述（带上下装会把镜头拉远）。
4. **零文字纪律**：角色图内不得有任何文字（图底声纹波形锚+≤8 词音色标签除外）；完整音色描述转纯文本交付。
5. **反派与特殊人群**：反派不过分丑陋；儿童老人仅剧本需要时出现。

## 六、场景资产规范

1. **每景 3–5 个锚点**：可画、可核对、用于 QC 时核对生成镜头漂没漂。
2. **光照状态从剧情反推**：只写用得上的状态（AI 换时段=重新生成不是重新打灯），每状态落完整提示词；能做变体就不开新景（variantOf 引用母场景）。
3. **三条提示词**：每场景给 正打/反打/侧面全景 三条，正反打按站位与对话方向设计，侧面全景交代完整空间调度。
4. **空景无人 + 提示词全英文 + 不含角色名**；时代场景必须带时代锚（年份+光源类型+服饰+建筑）防 AI 幻觉现代元素。
5. **群像判据**：有辨识度的固定群体（跨 ≥2 段/承担叙事功能/中近景以上）出群像卡；出戏个体必须升格为独立角色资产；无群像需求也要写一句显式声明，禁静默略过。

## 七、道具资产规范

1. **准入**：只收有特写、跨集、承载剧情的叙事道具，3–8 件（与主角数同量级）；一次性手部道具用镜头级提示词解决，不建资产。长在角色身上的细节（发饰/袖口/鞋）归角色细节图，不建道具资产。
2. **四格版式**：正面/45°侧/顶部俯视/细节特写；保留「左上角标注〔道具名〕」；禁人物/手/手持展示。
3. **状态弧**：合上/打开等状态 ≥1 是硬要求——每个状态一张参考图。
4. **白底无手**：道具图要贴进各种镜头必须可抠；「拿道具的手」是最常见污染源。
5. **尺度短语进提示词**：AI 常把手持道具画成家具尺寸（「掌心大小」「一臂长」）。

## 八、图像提示词条目规范（IMG-*）

- 条目结构：`## IMG-xxx · 中文名` + `- 参考：`（无外部参考写明；有图写 `REF-槽位（顺序）· 路径《中文名》（用途；控制；不得控制）`，多张分号连接顺序连续）+ `### 可复制提示词` 引用块（每行 `>` 开头）。
- 可复制正文规范：① 开头写对象和用途，不用风格词淹没身份；② 只包含当前图能同时满足的要求；③ 连续性锁点名的锁面**原样出现在正文里**；④ 文字/logo/水印/界面明确允许或禁止；⑤ 正文可直接复制，无占位符、无流程说明、无文件路径。
- 语言：按项目档案声明（默认英文）；不能从用户聊天语言推断提示词语言；同一任务内一致。
- 独立状态图：分镜需要尾帧时，把已接受的「收尾关键帧提示词」落实为独立 IMG 条目（注明来源 SHOT 与终点，不重新设计动作）。
- `IMG-*` 只代表提示词条目，不代表图已生成；`REF-*` 才指向项目内真实图片（总控状态机）。

## 九、输出与验收

- 交付三件套（缺一即不全）：素材清单状态表（⏳待生成/🔄沿用/✅已生成/❌待确认）+ 全套提示词（角色立绘+场景+道具+群像）+《素材接线单》（图号→类型→用途/控制什么/不控制什么→挂哪张）。
- 结构自检：条目自包含（禁「同上/见母版」跨条引用）；画幅与字段齐全；类型可判；编号只出现在标题与接线单、正文零编号字样；流程性内容物理隔离到文末。
- 一致性自检：每个身份资产的锚点唯一吗 / 提示词含角色名吗（分镜图例外）/ 空景无人吗 / 道具白底无手吗 / 状态弧齐吗 / 画风全剧统一吗 / 年龄性别年代是自己编的吗。

## 十、失败处理

- 剧本提及但视觉设定没有的物件：分镜侧逐镜用完全相同描述钉住并报告建议补条目；本模块不静默新增剧本事实。
- 参考图无法覆盖的要求（氛围层：光位/空气介质/色温/材质高光）：提示词写到死；参考图能覆盖的（脸/发/服装）只写一句「按图」。
- 出图效果确认：check 只能查尺寸/比例/背景白度，查不了长相/角度/取景——**出完必须看图，没看过图不说「效果很好」**。
