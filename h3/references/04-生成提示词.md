# 短剧全流程 Skill 套件 · 模块 04：生成提示词（图像 / 视频 / 模型适配）

## 一、职责与适用条件

**职责**：把分镜与资产意图转成可直接复制投喂的图像/视频生成提示词；维护「模型适配卡」接口。
**触发**：写图生/文生视频提示词、转格式、修生成失败、多段衔接、配乐提示词。
**不做**：改分镜边界、改台词、执行生成（归 05）、质检结论（归 06）。
**只交付可直接粘贴的提示词本体**——无开场白、无设计说明、无规则复述；参数（时长/画幅/分辨率）放正文外声明区。

## 二、输入与前置

分镜（SHOT+冻结关键帧+三依据）、视觉设定、素材形态与参考图三态（总控契约）、目标模型方言（适配卡）、生产档案（正文语言/原生时长区间/语速）。

## 三、通用提示词定律（跨模型，十条）

以下十条是各主流视频模型（时间线类如 Seedance/H3 系、即梦、可灵等）反复验证的共性律，与具体模型无关：

1. **提示词是随时间变化的规格，不是画面描述**：每句对应可见/可听事件并锚定时间戳（「At 5.5s…」/「0-3秒」）；无时间戳的连续描述会被平均成一锅。
2. **否定通道不可靠**：多数模型对否定词按词根渲染（「不要越轴」画出一条轴；「no push in」反而推镜）。执行纪律：①正文只写「存在的」——要「没有 X」就用「有什么」占满位置（`his head stays down` 代 `doesn't look up`）；②负面清单栏只装负面实例（no watermark / no plastic / no printed logos），禁否定式正向指令，禁长清单（稀释甚至召唤被禁物）。
3. **参考图决定「存在」，文字只写「做什么」与「不准变」**：人数、站位、空间、道具状态全靠参考图钉死，参考图喂给「决定存在」的那一步；文字负责动作与不变量。
4. **跨镜一致性靠逐字供给**：每段镜头是独立条件，6–8 个具体特征（身份/服装/发型/体态/光向/时代）**整段逐字重复**——paraphrase 就重骰脸；改任何规格前全文搜索旧表述并清干净（改景别后旧句子会「活过来」）。
5. **量化禁模糊词（词根清洗）**：模型按词找画面元素。九条改写公式：否定→正向占位；心理→8 部位生理证据；抽象→物理事实（「威严」→`he sits, everyone else stands`）；比喻→直陈；程度→量词；声音词只进声音层禁进画面；光效写材质本色+朝向不写「闪」；群体→数量+位置+状态；空词必删（atmospheric/moody/cinematic 只会回落训练集均值）。
6. **单镜预算**：一镜一个主动作（起手→接触→收势）+一个主运镜；一镜 ≤2–3 表演节拍（拆镜权在 03 模块）；10s 内 3–4 镜、15s 内 4–6 镜；「完全不动」合法且常更好。
7. **台词预算与语法**：台词秒数=字数÷语速（中文 4.3–4.5 字/秒、英文 2.2–3.0 词/秒）；逐字台词进专属台词标记（如 `<d>[语言]…</d>` 类，按适配卡），说话人用稳定 ID（S1/S2），VO 写明画外且嘴唇保持闭合；台词逐字来自剧本，不跨镜、不重复、不译写。
8. **首尾帧与段缝**：I2VA 类=首帧锚→动作启动→连续发展→结果反应；续接段绑定上一段**实际视频**+从该视频取的**实际尾帧**——未取得真实产物标「待续接、不可提交」，不用计划尾帧冒充接力输入；段尾留 1–1.5s 余裕（模型尾段有崩解区）。
9. **文字与屏幕内容不让模型画**：画内必须逐字可读的文字写明 字符/语言/承载面/位置（exact_readable）；系统面板/倒计时/字幕一律后期叠加（05 模块），正文直接声明「任何时刻都不生成字幕」。
10. **声音分层**：画内对白 / 画外音 / 旁白 / 环境声 / 动作音效 / 配乐各归其层；环境声连续、音效对齐可见接触、配乐独立层且在语音下避让；重要时刻前 1–2 秒静音放大冲击；无配乐时显式写 N/A，不留空让模型自配。

**通用红线**：不捏造参考 ID；不声称已生成；不承诺模型逐字执行；名词具体（写实例不写类别）；提示词内零平台名（合规 C 类），平台参数全部在适配卡。

## 四、图像提示词规范（IMG 正文）

结构顺序：主体与身份锚点 → 当前变体（只写允许变化的部分）→ 构图/视角 → 光色/材质 → 背景边界 → 禁止项。
- 身份锚点先写；被连续性锁点名的锁面原样进正文。
- 负空间充足；面部/手部清晰；三层纵深（前/中/景深背景）；参考图声明控制范围（用途；控制；不得控制）。
- 风格统一：一集所有图同一句画风、每个场景同一句光与色温；定调图先行，其余图引用其色调光线质感不取构图。
- 分镜关键帧图允许直呼角色名（唯一例外）；构图六字段（焦距/机位/构图/视线落点/焦点/稳定性）是构图全来源。

## 五、视频提示词规范（MOTION 正文）

条目骨架字段固定：`## MOTION-xxx · 中文名` + 分镜引用 + 时长 + 生成方式（只写「图生视频」/「文生视频」两精确值）+ 输入参考图（三态继承）+ 静态视觉锚点 + 起始帧 + 状态链（起点→唯一动作→终点）+ `### 可复制提示词` 引用块。
- **参考图三态执行**（继承总控）：REF-=图生视频（槽位/顺序/路径/用途/控制原样携带）；PLAN-=创作者自挂；「明确文生视频」=必须写非空静态视觉锚点纳入正文（不能只写 preserve）。
- **正文顺序**：静态锚点 → 起点 → 唯一动作 → 次级反应 → 运镜 → 声音 → 终点；相邻段在 {景别，角度，运镜类型，主体/视线} 至少 2 项不同，转场写成事件。
- **续接链**：同一连续时空相邻段默认「从上一段生成结果续接」；**剪接（换景别/正反打）不进同一条链**，各自从已接受起点生成；续接失败时按档案 `continuation_route`（independent_starts / relay_external）处理，不降级成独立文生视频。
- **时长门禁**：每镜时长必须落在目标模型原生区间（回分镜修订，不在正文暗改）；有对白时核对发声窗口（秒段加总正确≠台词说得完）。
- **声音同轨**：完整时间线（来源/说话人/语言/顺序，每句首字到末字）；无对白镜写清底声或静默及覆盖区间。
- **引文核对**：引号或台词标记内中文必须逐字来自《剧本.md》；台词不在剧本就回 01 模块改剧本，不在提示词里改。

## 六、模型适配卡（平台中立接口）

套件不内置任何平台语法；以下为已验证差异点清单，使用者按实际工具填卡（缺卡=只按第三节通用律写，并声明「未做模型适配」）：

| 适配项 | 需要确认的差异 |
|---|---|
| 单段时长区间 | 各模型 4–15s / ≤30s 等不同；段数=目标时长÷单段上限，在开工期判定 |
| 图槽上限 | 常见 ≤9 图/≤3 视频/≤3 音频/总 ≤12，也有放宽至 30 图的档位 |
| 台词/音效/音乐语法 | 各模型声音标记不同；同性别多说话人需声学对比拉满（音高/音质/语速） |
| 首尾帧支持 | 有模型支持首尾帧互斥模式，有的仅首帧；不支持首尾帧的禁用该参数 |
| 特效/顿挫词支持 | hit-stop、变速等并非全模型支持；不支持则改写为实时动作 |
| 排版模板 | 官方字段结构（如三字段/六段式）按所选模型官方指南填卡 |
| 帧网格 | 部分模型帧数须落在特定网格（如 17n+5）；不确认则不写帧数 |

适配卡纪律：一个项目一张卡、一次锁定；卡内字段与总控契约冲突时按裁决链处理；换模型=换卡+下游 STALE 重验。

### 已填卡 · H3 视频（本机唯一已填卡项，其余模型仍按附录 I 自填）

> 填卡依据：`h3-prompt-writing/SKILL.md` 与 `references/base-en.txt`（三栏结构与对齐句）、
> `h3-video-prompting/references/prompt-formats.md`（格式选型、字数与端点参数）、本机先导实测 n=3。
> 只摘参数与格式口径，不复制原文段落；权威仍是这两套 skill 的正文。

| 适配项 | 本机实填值 |
|---|---|
| 模型/工具 | MiniMax H3，五种输入模态：T2VA / I2VA / FL2VA / L2VA / Ref2VA |
| 单段时长区间 | **4–15 s**（下限 4、上限 15）；部分端点 T2V、I2V 只到 10 s，Ref2VA 到 15 s——开工前先确认端点，别按 15 s 排完再发现端点上不去 |
| 帧网格约束 | **17n+5**（15 s = 362 帧 = 17×21+5）；端点未确认就不写帧数 |
| 图槽上限 | 图 ≤9 / 视频 ≤3（各 2–15 s、总时长 ≤15 s）/ 音频 ≤3（同上）/ 总文件 ≤12；**音频不能单独上传**；prompt ≤7000 字符 |
| 首尾帧支持 | 是。I2VA=首帧锚、FL2VA=首尾帧、L2VA=尾帧；**首/尾帧模式不得与参考素材混用** |
| 台词语法 | 说话人用稳定 ID `(S1)` `(S2)`，多人齐说 `(S1,S2)`，同一人跨镜保持同 ID；台词**只**进 `<d>[语言] …</d>`；ID、指认短语、动作、语气一律写在 `<d>` 外，`<d>` 内只放语言标记 + 逐字原文（不译写、不改标点）；画外音写 `says in an off-screen voiceover` 并在同一句后写画面内角色嘴唇闭合；同一句跨切点两端写 `<scenetrans>` 并声明音频连续，被片尾截断写 `<cutoff>`；**中文台词在本地端不出声**，必须走 repo tokenizer 写 `<d>[Chinese] …</d>` |
| 音效/音乐语法 | 两栏英文散文：`overall_soundscape`（1–4 句，环境声/物理动作声/非语言人声，不复述台词与画内音乐）；`non_diegetic_music`（1–3 句，只写乐器/速度/节奏/动态，禁抽象情绪词，无则 `N/A`）。**H3 没有 `[SFX:]` 这类行内音效标记**（那是 Seedance 2.0 口径），禁止套用；也**没有独立负面提示词栏**，要"没有 X"必须正向点名占位 |
| 转场/特效支持 | 切镜写 `the camera cuts to` / `the shot cuts to` / `the shot transitions to`，并配 `[Shot N] At MM:SS.mmm` 严格递增时间戳；`[Shot 1]` **不带时间戳**，先写风格（`Live-action, cinematic` / `2D-animated` / `3D CG` / `claymation` / `watercolor`）；叠化、淡出、划像只在用户明确要求时用；只换距离或小角度优先用运镜不切镜；H3 由 Qwen3-VL 解析，形容词≠物理描述，不堆渲染词 |
| 排版模板 | **A 三栏（本机默认）**：`integrated_multimodal_description` + `overall_soundscape` + `non_diegetic_music`，I2VA/FL2VA/L2VA 首行加对齐句（秒数两位小数、对齐实际有效时长，其后空一行再进三栏）；**B 六段（Ref2VA 且有参考素材）**：`subject_definitions` / `summary` / `retention_analysis` / `detailed_description` / `overall_soundscape` / `non_diegetic_music`，`retention_analysis` 视觉用 `fully_preserved / partially_preserved / attribute_transfer / weak_reference`、音频用 `fully_copy / partially_copy / reference / weak_reference`；C 中文三段仅海螺 App/自然语言端点，D 社群区块式仅 hosted/第三方——**本地 ComfyUI 与导演台只认 A/B** |
| 写实皮肤锁 | 写实真人项目必写、正向点名：`matte realistic skin with visible pores and fine texture`，并写明完全无油光、蜡感、塑料磨皮；脸部特写另加 `absolutely no harsh specular hot spots`；禁写 `film grain` / `35mm` / `grain` / `beautified` / `retouched` / `flawless skin`（会被放大成重噪点或磨皮油腻脸）。非写实题材不写此锁 |
| 参考图接线 | 本地 ComfyUI Ref2VA：`ref_image_0 → <Picture 1>`、`ref_image_1 → <Picture 2>`，保留英文与尖括号、不写字段全名；同一角色多张图合成一个 `<Subject N>` 并声明为同一人的多视角，不得当成两个人 |
| 实测备注 | 本机先导 n=3（0.5MP / T2VA / 6 s）：带 `[Shot n] At` 时间戳的切点 6/6 落在 ±0.25 s（均值 0.045 s，无多余切点）；同题改散文、不加时间戳只有 2/6 命中目标。纯文字 300–700 英文字属社群经验值（官方无此数），Ref2VA 生成任务 350–500 英文。以上都记"实跑到 N"，不写"上限 N" |

填卡纪律（H3 专条）：① 段数 = 目标时长 ÷ 单段上限，在开工期算好，正文不暗改时长；② 换端点或换模型 = 换卡 + 下游标 STALE；③ 卡值与本机实测冲突时，以实测为准回写卡，并保留旧值改期记录。

## 七、商业风格模块（可选，广告/产品/垂类片段）

当任务是广告片/产品展示/垂类内容（而非剧情）时，按以下骨架替代叙事骨架：
1. **2 秒钩子**：开场 0–2s 必有钩子，从钩子库选型（附录 A），0.8–2s 内触发；「slow open」流失移动端观众。
2. **分镜时间轴**：0–2s hook / 2–6s 主运动 / 6–10s 次级运动 / 10–15s 收尾定格；每段一个主导动作，无静置超 2 秒。
3. **灯光三件套必答**：key（方向+色温）、fill（比例 3:1 标准/5:1 戏剧）、rim（有无+强度）——缺一即 flat lighting；美食用 45° 暖主光（2700–3200K）+逆光显蒸汽；产品按品类查灯位表（附录 C）。
4. **材质句式**：每种材质写「运动法+光法」配对（附录 D）。
5. **声音语义**：声音=体验代理，每个动作一个主导声+底层 ambience（附录 E）。
6. **文字叠加**：每条 ≤8 词、同屏 ≤3 行、停留 ≥1–2s、错峰出现；正文最小 24pt@1080p。
7. **音量分层**：dialogue 0dB、music -2~-4dB、SFX +1~+3dB、ambient -3~-6dB；音画同步 ≤50ms。
8. 自检五问：前 2 秒抓人吗 / 利益/卖点清楚吗 / CTA 明确吗 / 风格合品牌吗 / 对比度够吗。

## 八、输出与验收

- `剧集/<EP>/图片提示词.md`、`剧集/<EP>/视频提示词.md`（条目化，字段齐全，无整行删除）。
- 完成标准：每条正文可直接复制投喂（零占位符）；三态参考图逐字合规；时长全部落在模型区间；台词逐字可溯源剧本；正文语言与档案声明一致；跨镜不变量逐条重复到位。
- 自检（送出前八问）：每镜一个主动作吗 / 时间戳连续无重叠吗 / 逐字一致性到位吗 / 否定词清零吗 / 模糊词清洗过吗 / 台词预算对吗 / 参考图三态对吗 / 正文外参数分离吗。

## 九、失败处理

- 生成结果与提示词不符：取证→定位病灶句→只改病灶→复验零新增（不是重写全篇）；三种典型症状速查：画面冻住=节拍超载或时间戳断；脸漂=一致性特征没逐字重复或多镜一次生成；文字乱码=把文字交给了模型（改后期叠加）。
- 多次失败按 03 模块「改镜不改词」规则升级。
- 适配卡与实测不符：以实测为准回写适配卡，并记录「实跑到 N」不写「上限 N」。
